Build a polished, responsive single-page website for a fictional technology conference called "Orbit 2026". Work autonomously and complete the implementation in this directory.

Requirements:
- Use only HTML, CSS, and vanilla JavaScript. Do not use external packages, CDNs, remote images, or network resources.
- The entry point must be index.html and it must work when served by a basic static HTTP server.
- Include a sticky navigation bar, hero section, event statistics, speaker cards, schedule, ticket tiers, and footer.
- Add a mobile navigation button with id="nav-toggle". It must update aria-expanded and show or hide the navigation links.
- Add a light/dark theme button with id="theme-toggle". Persist the chosen theme in localStorage under the key "orbit-theme".
- Add a newsletter form with id="newsletter-form", an email input with id="email", and a status element with id="form-status". Invalid submissions must display an error; valid submissions must display a success message without reloading the page.
- Make the page visually intentional at 390px and 1440px widths, keyboard accessible, and respectful of prefers-reduced-motion.
- Use semantic HTML, visible focus states, and sufficient color contrast.
- Add a README.md explaining how to run and inspect the site.
- Before finishing, inspect your files and perform whatever local verification is practical. Do not merely describe code: create the finished website.
