Build a polished, responsive personal-finance dashboard called "Ledgerly". Work autonomously and complete the implementation in this directory.

Requirements:
- Use only HTML, CSS, and vanilla JavaScript. Do not use external packages, CDNs, remote images, or network resources.
- The entry point must be index.html and it must work when served by a basic static HTTP server.
- Organize the JavaScript cleanly; multiple source files are allowed.
- Show summary cards for current balance, total income, and total expenses.
- Include a transaction table and seed at least five realistic transactions only when no saved data exists.
- Provide a transaction form with id="transaction-form" containing controls with ids "description", "amount", "type", "category", and "date".
- Users must be able to add and delete transactions. Each rendered transaction must use an element with class="transaction-row" and its delete control must have class="delete-transaction".
- Validate empty descriptions, non-positive or invalid amounts, and missing dates. Display feedback in an element with id="form-error" without reloading the page.
- Provide search with id="search", type filtering with id="type-filter", category filtering with id="category-filter", and sorting with id="sort-by". Filters must work together.
- Add a monthly budget input with id="budget-input", a save button with id="save-budget", and a visible budget progress indicator. Handle zero budget and overspending without invalid percentages or broken layouts.
- Persist transactions and budget in localStorage using keys "ledgerly-transactions" and "ledgerly-budget".
- Include meaningful empty states, a reset-filters control, responsive mobile and desktop layouts, semantic HTML, keyboard accessibility, visible focus styles, and prefers-reduced-motion support.
- Add a light/dark theme control and persist it under "ledgerly-theme".
- Add a README.md explaining architecture, storage, and how to run the site.
- Before finishing, inspect your implementation and perform whatever local verification is practical. Do not merely describe code: create the complete working website.
